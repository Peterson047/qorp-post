## Como Adicionar Novos Posts

1. Crie um novo arquivo na pasta `_posts/`
2. Nomeie no formato: `YYYY-MM-DD-titulo-do-post.md`
3. Adicione o front matter (o bloco entre `---` no início)
4. Escreva seu conteúdo em markdown
5. Commit e push para o GitHub!

## Formatação Markdown

Você pode usar toda a sintaxe markdown:

- **Negrito** e *itálico*
- [Links](https://github.com)
- Listas como esta
- `código inline`
- Blocos de código:

```javascript
function hello() {
  console.log("Olá, mundo!");
}
```

> Citações também funcionam!
